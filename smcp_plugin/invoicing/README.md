# Invoicing SMCP plugin

CLI wrapper around `invoicing_sdk.InvoicingClient`.

```bash
export INVOICING_API_BASE_URL=https://dev.invoicing.decisionsciencecorp.com
export INVOICING_SMCP_API_KEY=...
python3 smcp_plugin/invoicing/cli.py list-companies
python3 smcp_plugin/invoicing/cli.py --help-all
```
